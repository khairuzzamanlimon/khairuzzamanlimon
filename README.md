## 👨‍💻 About Me

I'm **Limon**, a student and developer who enjoys building practical software, experimenting with new technologies, and turning ideas into real experiences.

- 🎓 Student who is always learning and exploring
- 💻 Interested in **web development, mobile development, backend systems, cloud, and DevOps**
- 🧩 I enjoy working across the stack — from UI and APIs to databases, storage, and servers
- ⚙️ Interested in **self-hosting, automation, performance, and infrastructure**
- 🌱 Currently learning more about **backend development, system design, cloud, and DevOps**
- 🎯 Goal: keep learning, keep building, and create things that are genuinely useful
- ⚡ Fun fact: I can spend way too much time fixing one tiny bug 😆
