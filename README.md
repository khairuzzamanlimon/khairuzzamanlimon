## 🚀 Featured Project

### 🎬 TNGFLIXBD

A full-stack movie streaming platform built around a React + Node.js architecture.

**Core Stack:**

`React` `Vite` `Tailwind CSS` `Zustand` `Node.js` `Express` `SQLite` `Supabase` `Cloudflare R2`

**Highlights:**

- 🎨 Netflix-inspired dark UI
- 🔐 Authentication with Supabase
- 🗄️ SQLite for application and movie data
- ☁️ Cloudflare R2 for storage
- 🖥️ Express backend with modular routes
- 🛠️ Admin panel and streaming-focused infrastructure
- 🚀 Built with a focus on maintainability and practical deployment
