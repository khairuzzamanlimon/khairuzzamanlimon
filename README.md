## 🚀 Featured Project

### 🎬 TNGFLIXBD

A full-stack movie streaming platform built with a modern React + Node.js architecture.

**Stack:** React • Vite • Tailwind CSS • Zustand • Node.js • Express • SQLite • Supabase • Cloudflare R2

- 🎨 Netflix-inspired dark UI
- 🔐 Authentication with Supabase
- 🗄️ SQLite-based application data
- ☁️ Cloudflare R2 for storage
- 🖥️ Express backend with modular routes
- 🛠️ Admin panel and streaming-oriented infrastructure
